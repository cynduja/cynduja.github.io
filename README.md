# Sinduja Rangarajan — personal site for GitHub Pages

Quick start
1) Create a public repository named `USERNAME.github.io`
2) Upload these files to the repo root
3) Commit to `main`
4) Visit `https://USERNAME.github.io`

Personalize
- Edit `index.html` and `projects/index.html`
- Replace `resume/resume.pdf` with your real resume
- Update links for LinkedIn and GitHub
